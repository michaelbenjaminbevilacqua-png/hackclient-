## Quick Start with GitHub Codespaces

### Opening a Codespace

1. Click the **<> Code** button on this repository
2. Select the **Codespaces** tab
3. Click **Create codespace on main**
4. Wait for the Codespace environment to initialize (this takes a few minutes on first setup)

### Codespace Setup

Once your Codespace is running, the environment will be ready to use with:
- Full terminal access
- Pre-configured development tools
- All repository files available
